모션 템플릿 스튜디오 사용법

모션 템플릿 스튜디오는 설치 없이 브라우저에서 바로 쓰는 무료 모션그래픽 편집기입니다. 드라마 타이틀, K-POP 가사 영상, 브랜드 광고, 뉴스 오프닝, 숏폼 훅 등 67가지 템플릿에서 시작해 장면·자막·전환·효과음·음악을 하나씩 바꾸고, 완성된 영상을 WebM 파일로 내보낼 수 있습니다. 모든 그림과 소리는 브라우저가 직접 그리고 합성하므로 별도의 소스 파일이 필요 없습니다.

  1. 템플릿 고르기 — 오른쪽 ‘템플릿’ 탭에서 카테고리를 누르거나 “네온”, “세로”, “피아노”처럼 검색합니다.
  2. 트랙별로 고치기 — 타임라인의 화면·자막·전환·효과음·음악 트랙에서 항목을 누르면 그 부분만 편집 창이 열립니다.
  3. 에셋 끌어다 놓기 — ‘에셋’ 탭의 장면·전환·효과음 카드를 타임라인으로 끌어다 놓으면 바로 들어갑니다. 카드에 마우스를 올리면 움직임을 미리 볼 수 있어요.
  4. 색·서체·효과 — ‘효과·색’ 탭에서 팔레트, 서체, 화면 비율(16:9·9:16·1:1), 필름 그레인·레터박스 등을 조절합니다.
  5. 화면에서 바로 편집 — 미리보기 화면의 글자나 사진을 클릭하면 그 항목의 편집 창이 열리고, 끌면 위치가, 모서리 점을 끌면 크기가 바뀝니다. ‘추가 요소’로 텍스트나 로고를 원하는 곳에 더 올릴 수 있습니다.
  6. 도구 막대 — 미리보기 아래 막대에서 선택한 글자·그림의 색, 크기, 회전, 투명도를 바꾸고 도형·아이콘·텍스트·이미지를 추가합니다. 빈 곳을 끌면 장면의 내용 전체가 움직이고, 장면만의 색과 확대도 여기서 조절합니다.
  7. 사진·로고 넣기 — ‘사진 히어로’, ‘로고 리빌’, ‘스마트폰 목업’ 같은 장면은 ‘장면·기법’ 탭에서 내 이미지를 넣을 수 있습니다. 미리보기 화면에 파일을 끌어다 놓아도 됩니다.
  8. 되돌리기·단축키 — Ctrl+Z / Ctrl+Shift+Z로 되돌리기·다시 실행, Ctrl+D 장면 복제, Del 삭제, PgUp·PgDn 장면 이동.
  9. 내보내기 — ‘영상 내보내기’를 누르면 영상 길이만큼 실시간 녹화한 뒤 WebM 파일로 저장합니다.
67개 템플릿플랫 일러스트 로맨스, 키네틱 타이포, 다크 스릴러, 동양 판타지, 뉴스, 게임, 요리, 시즌 이벤트, 회사 소개, 채용, 세일 광고, 사진 슬라이드, 카드뉴스 등 11개 카테고리.
500여 개 에셋장면 프리셋 200여 개, 일러스트 90종, 전환 24종, 텍스트 등장 22종, 효과음 30종, 음악 16종.
내 데이터는 내 브라우저에작업 내용은 서버로 보내지 않고 브라우저에만 자동 저장됩니다. ‘프로젝트 저장’으로 파일 백업도 가능해요.

자주 묻는 질문

MP4로 저장할 수 있나요?

네. 크롬·엣지 최신 버전에서는 내보내기 버튼 옆에서 MP4를 고르면 바로 MP4로 저장됩니다. MP4 녹화를 지원하지 않는 브라우저에서는 WebM으로 저장되며, HandBrake·캡컷·프리미어 프로에서 변환할 수 있습니다.

만든 영상을 상업적으로 써도 되나요?

네. 스튜디오의 일러스트·음악·효과음은 모두 코드로 새로 만든 것이라 자유롭게 쓸 수 있습니다. 직접 올린 음악·효과음 파일의 권리는 올린 분이 확인해 주세요.

휴대폰에서도 되나요?

편집과 미리보기는 됩니다. 다만 끌어다 놓기와 영상 내보내기는 데스크톱 크롬·엣지에서 가장 안정적입니다.

작업한 내용이 사라졌어요.

작업 내용은 브라우저 저장소에 자동 저장되므로, 브라우저 기록·사이트 데이터를 지우거나 시크릿 창을 닫으면 사라집니다. 중요한 작업은 ‘프로젝트 저장(.json)’으로 파일을 보관하세요.
