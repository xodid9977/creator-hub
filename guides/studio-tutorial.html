템플릿 스튜디오 사용법: 5분 만에 첫 영상 만들기

2026-11-09 · Creator Hub 가이드

템플릿 스튜디오는 설치 없이 브라우저에서 바로 쓰는 모션그래픽 편집기입니다. 모든 그림·애니메이션·소리를 브라우저가 직접 만들어 내기 때문에 파일을 올릴 필요도 없습니다. 처음 쓰는 분을 위해 순서대로 안내합니다.

1단계. 템플릿 고르기

오른쪽 패널의 템플릿 탭에서 카테고리(드라마 타이틀, 뮤직·가사, 브랜드·광고, 정보·홍보, 유튜브·숏폼, 이벤트·시즌 등)를 누르거나 검색창에 “네온”, “세로”, “피아노”처럼 입력해 찾습니다. 카드를 누르면 장면 구성, 기법, 전환, 효과음, 음악이 한 번에 세팅됩니다. 마음에 안 들면 알림창의 ‘되돌리기’를 누르세요.

2단계. 타임라인 트랙 이해하기

미리보기 아래 타임라인은 다섯 줄로 나뉘어 있습니다.

  • 화면: 장면 썸네일. 누르면 일러스트·길이·순서 편집.
  • 자막: 장면별 글자와 등장 기법. 누르면 텍스트 입력칸으로 바로 이동.
  • 전환: 장면 사이의 화면 전환. 누르면 전환 고르기 화면이 열림.
  • 효과음: 시간 위치에 놓인 소리들. 누르면 그 소리가 들리고 바꿀 수 있음.
  • 음악: 배경 음악. 누르면 사운드 탭으로 이동.

트랙의 빈 곳을 드래그하면 영상을 앞뒤로 훑어볼 수 있고, 스페이스바로 재생·정지합니다.

3단계. 글자 바꾸기

‘자막’ 트랙에서 장면을 누르고 메인 텍스트와 보조 텍스트를 고칩니다. 장면 종류에 따라 입력 규칙이 조금 다릅니다. 메신저 장면은 줄마다 말풍선 하나, 키네틱 슬램은 띄어쓰기마다 한 단어, 그래프 장면은 보조 텍스트에 숫자를 띄어 쓰면 값이 됩니다.

4단계. 에셋에서 가져오기

에셋 탭에는 장면 프리셋 200여 개, 일러스트 90종, 전환 24종, 텍스트 등장 22종, 효과 프리셋, 팔레트, 서체, 효과음, 음악이 모여 있습니다. 카드에 마우스를 올리면 움직임을 미리 볼 수 있고, 버튼을 누르거나 카드를 타임라인으로 끌어다 놓으면 바로 들어갑니다. 장면은 놓은 자리에 끼워지고, 전환·등장·효과음은 놓은 장면에 적용됩니다.

5단계. 색과 효과

효과·색 탭에서 다섯 가지 팔레트 색, 제목·본문 서체, 출력 비율(16:9 / 9:16 / 1:1), 필름 그레인·레터박스·글리치 같은 전역 효과를 조절합니다.

6단계. 소리

사운드 탭에서 배경 음악 16종 중 하나를 고르고 템포와 볼륨을 맞춥니다. 내 음악 파일이나 효과음 파일을 올릴 수도 있습니다(올린 파일은 이 브라우저 탭에서만 쓰입니다).

7단계. 내보내기와 저장

  • 영상 내보내기(.webm): 실시간으로 녹화하므로 영상 길이만큼 기다리면 됩니다. 녹화 중엔 탭을 바꾸지 마세요.
  • MP4가 필요하면 HandBrake, 캡컷, 프리미어 등에서 WebM을 변환하세요.
  • 프로젝트 저장(.json): 편집 상태를 파일로 저장해 두었다가 ‘프로젝트 불러오기’로 이어서 작업할 수 있습니다. 편집 중인 내용은 브라우저에도 자동 저장됩니다.
개인정보: 스튜디오에서 만든 내용은 서버로 보내지지 않고 사용자의 브라우저 안에서만 처리·저장됩니다.
